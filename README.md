# المصحف الشريف — تطبيق (أندرويد + آيفون + ويب)

مصحف برواية حفص عن عاصم: فهرس السور، الأجزاء، العلامات، البحث، عرض الصفحات، يعمل دون إنترنت.
الكود كله في `www/index.html`. التغليف بـ Capacitor، والبناء تلقائي عبر GitHub Actions.

## الرفع والبناء
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد (فرع `main`).
2. من تبويب **Actions** سيعمل تلقائياً: `Build Android APK` و`Build iOS (unsigned IPA)` (أو شغّلهما يدوياً Run workflow).
3. بعد نحو ٥–١٠ دقائق افتح التشغيلة وحمّل من **Artifacts**: `mushaf.apk` (أندرويد) و`mushaf-unsigned.ipa` (آيفون).
4. لنشر نسخة في Releases: `git tag v1.0.0 && git push --tags` وسيُرفق الملفان تلقائياً.

## التثبيت
- **أندرويد:** انقل `mushaf.apk` للهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»). هذه نسخة debug للتجربة؛ للنشر على Google Play يلزم توقيع release.
- **آيفون:** الـ IPA غير موقّع، فلا يُثبَّت مباشرة. الخيارات: التثبيت عبر Sideloadly/AltStore بحساب Apple مجاني (صلاحية ٧ أيام)، أو حساب Apple Developer للتوقيع والنشر على TestFlight/App Store. **أسهل طريق بلا حساب:** انشر مجلد `www` على GitHub Pages، وافتحه في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية» (يعمل دون إنترنت ويستخدم manifest وservice worker).

## تغيير معرّف التطبيق أو اسمه
عدّل `appId` و`appName` في `capacitor.config.json`. الأيقونة والسبلاش من مجلد `assets/`.
